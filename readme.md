# Python for AI Foundations

A collection of Python programming and numerical computing exercises covering core concepts needed for Artificial Intelligence, Machine Learning and scientific computing.

This repository documents my practice with Python fundamentals, data structures, NumPy and mathematical operations.

## Topics Covered

### 1. Python Functions
- Unit conversion using custom functions
- Mathematical operations on numerical lists
- Error handling using `try-except`
- Function parameters, return values and docstrings

### 2. List Manipulation
- List slicing and indexing
- Extracting elements using slicing
- Reversing lists
- Accessing and modifying list elements
- Working with nested lists

### 3. Nested Lists
- Flattening nested lists
- Recursive operations on nested structures
- Accessing nested elements
- Calculating sums, averages and maximum values
- Counting element occurrences

### 4. NumPy Fundamentals
- Array creation and initialization
- Array indexing and slicing
- Reshaping and concatenation
- Vector and matrix operations
- Matrix multiplication and dot products
- Identity matrices and inverse matrices
- Solving systems of linear equations

### 5. Performance Experiments
Comparing Python lists and NumPy arrays through:
- Element-wise addition
- Element-wise multiplication
- Dot products
- Matrix multiplication
